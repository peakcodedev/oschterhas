# App-Icons

Homescreen-Icons für die Webapp (PWA). `oschterhas-app-icon` hat abgerundete Ecken für normale Icons. `oschterhas-app-icon-maskable` füllt die ganze Fläche und hält das Motiv in der sicheren Zone, damit Android es selbst zuschneiden kann. `apple-touch-icon.png` (180px) ist für iOS. Der Hintergrund ist immer `eigelb`.
